## New

- **No more English-only matching.** The plugin finds the Reject button by its position in the banner, not its label, so it should work in any Twitch language. Only English has been tested so far.
- **Faster.** A small watcher in each Twitch dock rejects the banner as soon as it appears, instead of the plugin checking every 2 seconds.
- **Bug report form.** If a banner isn't rejected, the [issue form](https://github.com/Jayconius/obs-reject-cookies/issues/new?template=banner-not-rejected.yml) asks for the details needed to fix it.

## Fixed

- **Chat dock sometimes kept its banner.** A click made the moment the banner appeared could be ignored by Twitch, and quiet docks like Chat never got a second try. The plugin now retries until the banner closes.

## Other

- Release zips are now built by GitHub Actions from the tagged source.

## Install

1. Download `obs-reject-cookies-1.1.0-windows-x64.zip` below.
2. Close OBS.
3. Extract the zip into your OBS folder (for example `C:\Program Files\obs-studio`, or your portable folder). `obs-reject-cookies.dll` should end up in `obs-plugins\64bit`.
4. Start OBS.

Requires OBS 31 or newer on Windows (64-bit). Tested on OBS 32.2.1.
