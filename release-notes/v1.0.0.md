First release.

An OBS Studio plugin that automatically clicks **Reject** on Twitch's "Cookies and Advertising Choices" banner in OBS's built-in Twitch docks (Chat, Stats, Activity Feed, Stream Info), so you don't have to pop each dock out to reach a button that's cut off.

## Install

1. Download `obs-reject-cookies-1.0.0-windows-x64.zip` below.
2. Close OBS.
3. Extract the zip into your OBS folder (for example `C:\Program Files\obs-studio`, or your portable folder). `obs-reject-cookies.dll` should end up in `obs-plugins\64bit`.
4. Start OBS.

Windows (64-bit) only. Tested on OBS 32.2.1.
