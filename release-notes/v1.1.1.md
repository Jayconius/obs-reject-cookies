## Fixed

- **Banners left showing when OBS starts slowly.** If a Twitch dock was still loading a few seconds after OBS opened, which happens on setups with lots of sources and plugins, it could miss the plugin and keep its banner. The plugin now checks every dock every 2 seconds, so a slow dock is covered whenever it finishes loading.
- **Reject clicks that didn't take.** If Twitch ignores a click on Reject, the plugin now keeps retrying until the banner closes. Before, it gave up after a minute.

## Install

1. Download `obs-reject-cookies-1.1.1-windows-x64.zip` below.
2. Close OBS.
3. Extract the zip into your OBS folder (for example `C:\Program Files\obs-studio`, or your portable folder). `obs-reject-cookies.dll` should end up in `obs-plugins\64bit`.
4. Start OBS.

Updating from an earlier version: extract over the top and replace the existing file.

Requires OBS 31 or newer on Windows (64-bit). Tested on OBS 32.2.1.

Banner still showing? [Report it here](https://github.com/Jayconius/obs-reject-cookies/issues/new?template=banner-not-rejected.yml).
